Decisions I made where the spec was silent

  • Absolute sizes → ratios. Everything is --canvas × ratio (--canvas = min(100vw, 1920px)): name 78, subtitle 30, body 24, radius 45. Proportions hold below the 1920 canvas.
  • Left / right = one modifier. .pkt-mcard--left / --right set the background and flip the image side with order. The details markup is identical for both.
  • Vertical anchoring. Name + subtitle sit at the top; the separator + body + arrow are margin-top: auto to the bottom (spec: name anchor "top", separator anchor "bottom"). The tall image fills the height between.
  • Separator orientation. Spec says width: 1, height: 783. Read as a horizontal rule (1px thick, ~783 long ≈ the details column) above the body — matching "other_text under separator". If it was meant to be a vertical divider, say so. Rendered full-width of the details column rather than a fixed 783.
  • "Discover more" is the link. The separator + arrow + body form one <a> to the machine page, with an aria-label (the body text alone isn't descriptive). Arrow nudges right on hover; reduced-motion respected.
  • Arrow uses brand red #FF0000 — overriding the #FF3B30 in right_arrow.svg so it matches the hero/footer. Update the source SVG to match when it's imported.
  • Card is intentionally light (no dark-mode flip) — it's a white/grey surface by spec, like the footer is black. Only the preview page chrome is theme-aware.
  • Font. All text is "Mittel" → font-weight: 500; Apfel Grotezk falls back to Helvetica until the licensed webfont lands.
  • Subtitle \n from the spec is rendered as a <br> after "Oltre la carta:".
