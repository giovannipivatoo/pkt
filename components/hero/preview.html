Decisions I made where the spec was silent

  • Absolute coordinates → ratios. Every value is --canvas × ratio, where --canvas is min(100vw, 1874px). The proportions from Figma hold at 1440, 1280, or 390 wide — hardcoded x/y would have broken on every laptop.
  • Two paddings unified. Nav inset computes to 37.5 (1874−1799 ÷ 2) and title x is 31. Six pixels apart, almost certainly not intentional — both are now --pad at 2%. Say the word if the difference is real.
  • Font. Apfel Grotezk is declared first but no file exists, so it falls back to Helvetica. Drop the .woff2 in and add one @font-face — nothing else changes. It is a commercial font: PKT needs a webfont licence.
  • Title anchored to the bottom rather than pinned at y:496, since hero height "varies based on background height". Content grows upward from the baseline instead of overlapping the nav on short viewports.
  • Mobile (<900px) was unspecified: links collapse into a native <details> menu, columns stack. No JavaScript — the zero-JS rule holds.
  • Hover and focus were unspecified: a red underline on both, matching the logo's #FF0000. Focus is visible for keyboard users.
  • "Pkt" moved into the right-hand group, as its first item. Note that pkt and packaging_solutions are now both at x:992 in the spec — the others kept their old coordinates, so the collision is presumably just un-updated numbers. Flex spacing handles it either way, but confirm the order is Pkt → Packaging Solutions → Sostenibilità → Feed → Contatti.
