Decisions I made where the spec was silent

  • Absolute coordinates → ratios. Everything is --card × ratio, where --card is min(100%, 659px). The gap (18 / 659) and title (40 / 659) hold at any grid column width — a fixed 659 card would overflow a 3-up grid on a laptop.
  • Image via aspect-ratio: 659 / 474 instead of a hardcoded height, so it scales with the column. Swap the placeholder <div> for the CMS <img class="pkt-cat__img"> — object-fit: cover is already set. The alt should be the category name (a11y).
  • Whole card is a link to the category page. The spec gives no target, but a category card in a listing is clickable — heading sits inside the <a>.
  • Subtitle colour not in spec. Uses an ink token that flips for dark surfaces, since the card background is transparent and inherits the page. Confirm the colour.
  • Font. Apfel Grotezk is declared first but no file exists, so it falls back to Helvetica — same commercial-webfont licence note as the hero.
  • Hover / focus were unspecified: image scales to 1.02 and the title turns #FF0000, matching the brand. Reduced-motion is respected.
  • Long names wrap under the image and grow the card downward (spec H 542 assumes one line). Fine in a grid; rows align to the tallest card.
